# AEC v0.1.0

This beta release establishes the first consumer-readable AEC release manifest.

Consumers must treat the attached exact Git revision as a candidate, not as automatic
authorization to update. Before changing a pin, run the routine, material-decision, and
human-render compatibility probes at that exact revision. Consumer projects own their
update branch, pull request, review, merge, deployment, and rollback.

This release does not permit auto-merge and does not make AEC authoritative over any
consumer lifecycle or project state.

Publication is bound to the exact dereferenced tag commit. A recovery dispatch requires
both the existing release tag and its expected full commit SHA, then proves the tag,
current-main lineage, repository immutability, and release absence through authenticated
GitHub API responses. It never moves or recreates the tag and never packages floating
`main`.
