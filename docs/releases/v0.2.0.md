# AEC v0.2.0

This beta release adds consumer-owned notification for reviewed AEC releases and
the task-intake guidance contract proven with real Claude and Codex consumers.

Consumers can now keep one tracked `.aec-pin`, copy the standard-library release
checker and scheduled workflow from `docs/consumer-kit/`, and receive one
deduplicated issue when the official release manifest names a different exact
revision. The workflow never executes the candidate or changes consumer code,
pins, pull requests, deployments, or lifecycle state.

Before adopting this release, update `.aec-pin` on a consumer-owned branch and
run the manifest's routine, material, and human-render probes against the exact
revision. This release remains `validation-required` and does not permit
automatic merge.
